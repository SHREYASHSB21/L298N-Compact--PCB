# L298N Compact Motor Driver PCB

Compact L298N motor driver PCB with integrated 7805 regulator and flyback diode protection using KiCad

## Features

- Size 84.58 mm x 20 mm
- Compact single-layer layout
- Integrated 7805 voltage regulator
- External flyback diode protection
- Screw terminals for motors and power
- 5V indicator LED
- Easy header interface for microcontrollers

## Software

- KiCad 9

## Applications

The **L298N Compact Motor Driver PCB** is a plug-and-play dual H-Bridge motor driver designed for seamless integration with microcontrollers such as **Arduino, ESP32, STM32, and Raspberry Pi Pico**. Simply connect the power supply, motor outputs, and control pins to quickly drive two DC motors without additional motor driver circuitry.

- Line Following Robots
- Obstacle Avoiding Robots
- Bluetooth Controlled Robots

- Autonomous Mobile Robots (AMRs)
